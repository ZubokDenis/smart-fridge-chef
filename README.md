# ПОЯСНИТЕЛЬНАЯ ЗАПИСКА К ПРОЕКТУ
## «Умный Шеф: Холодильник & Рацион» (Smart Fridge Chef)
### Программный комплекс на базе WordPress с мультимодальным ИИ и геомодулем

---

## 1. Паспорт проекта и общие сведения

- **Наименование проекта:** Программный комплекс «Smart Fridge Chef» («Умный Шеф: Холодильник & Рацион»).
- **Платформа реализации:** [WordPress 6.x](file:///c:/Users/Denis/Documents/antigravity/delightful-faraday/wordpress) (Headless CMS / REST API + Single Page Application Frontend).
- **Среда исполнения:** Автономная портативная среда [PHP 8.3 x64](file:///c:/Users/Denis/Documents/antigravity/delightful-faraday/tools/php/php.exe) со встроенной реляционной СУБД SQLite 3 (не требует развертывания Docker или служб MySQL).
- **Дизайн-система:** Синтез стандартов **Google Material Design 3 (M3)** и эргономики **Instagram Web UI**.
- **Интеллектуальное ядро:** Мультипровайдерный AI-модуль с поддержкой **Anthropic Claude (Claude 3.5 Sonnet / Haiku)**, **Ollama Cloud**, локальной **Ollama** (`llama3.2-vision`, `llava`, `qwen2-vl`), **Google Gemini** и детерминированного экспертного кулинарного движка (Rule-based Fallback Engine).
- **Версия продукта:** `1.2.0 (Production-Ready)`.

## 2. Актуальность и проблематика

Современный человек ежедневно сталкивается с тремя взаимосвязанными бытовыми проблемами:
1. **Нерациональное использование продуктов питания (Food Waste):** по статистике до 25–30% купленных продуктов выбрасываются из-за истечения срока годности или забывания того, что находится на полках холодильника.
2. **Когнитивная нагрузка при планировании питания:** ежедневный выбор блюд на завтрак, обед и ужин отнимает время, приводит к однообразному рациону и нарушению баланса белков, жиров, углеводов и калорийности (КБЖУ).
3. **Неэффективная логистика покупок:** составление списков покупок вручную часто приводит к дублированию позиций, покупке лишнего и выбору неподходящего магазина (например, поход в эконом-дискаунтер за редкими соусами или в премиум-гастроном за базовой бакалеей).

**Цель проекта:** разработать легкий, автономный и интуитивно понятный программный комплекс, позволяющий пользователю по одной фотографии холодильника или списку ингредиентов сформировать персональную базу продуктов, сгенерировать адаптивные рецепты, составить сбалансированное меню на неделю, рассчитать точный список недостающих ингредиентов и подобрать оптимальный супермаркет поблизости с помощью нейросетей и геоданных.

- **Бэкенд:** PHP 8.3 x64, WordPress 6.7.x, WordPress REST API, cURL, GD/Image Processing, JSON Schema.
- **База данных:** Реляционная СУБД SQLite 3 через официальный drop-in драйвер `db.php` команды WordPress Core (гарантирует zero-dependency переносимость без сторонних СУБД-серверов).

## 4. Функциональная структура программного комплекса

### 4.1. Модуль компьютерного зрения и инвентаризации продуктов ([class-ai-engine.php](file:///c:/Users/Denis/Documents/antigravity/delightful-faraday/wordpress/wp-content/plugins/smart-fridge-chef/includes/class-ai-engine.php))
- **Загрузка и предобработка изображений:** поддержка Drag & Drop, выбора файлов с диска и прямой съемки с камеры мобильного устройства (форматы JPEG, PNG, WebP).
- **Мультимодальное распознавание:** передача Base64-образа изображения в нейросетевую модель (Claude 3.5 Sonnet, Ollama Cloud `llama3.2-vision`, Google Gemini).
- **Парсинг и нормализация:** ИИ извлекает структурированный JSON с полями: название продукта, примерное количество, категория (овощи, мясо/птица, молочное, бакалея и др.), оценка срока хранения.
- **Текстовый ввод:** параллельная возможность добавления продуктов через текстовое поле или быстрые теги с автоматической нормализацией словоформ к начальной форме (стемминг/стем-рутинг).

### 4.2. Модуль подбора рецептов и расчета пищевой ценности
- **База рецептур:** содержит каталогизированные рецепты русской, европейской, средиземноморской и азиатской кухонь.
- **Алгоритм сопоставления:** оценивает процент покрытия ингредиентов из текущего инвентаря холодильника.
- **Расчет КБЖУ:** для каждого рецепта вычисляется и отображается калорийность, белки, жиры, углеводы и время приготовления.
- **Инструкции по приготовлению:** пошаговые сценарии термообработки и подготовки ингредиентов.

### 4.3. Модуль генератора недельного рациона (Meal Planner)
- **Структура на 7 дней:** автоматическое распределение приемов пищи (Завтрак, Обед, Ужин, Перекус) с понедельника по воскресенье.
- **Оптимизация остатков:** алгоритм планирует меню таким образом, чтобы скоропортящиеся продукты из холодильника использовались в первые 2–3 дня недели.
- **Персистентность:** сохранение готового недельного плана в базу данных WordPress как кастомный тип записи [`sfc_meal_plan`](file:///c:/Users/Denis/Documents/antigravity/delightful-faraday/wordpress/wp-content/plugins/smart-fridge-chef/includes/class-post-types.php) с возможностью повторного открытия и печати.

### 4.4. Модуль разностного расчета корзины покупок (Shopping List Diff)
- **Формула расчета:**
  $$\text{Список к закупке} = \sum (\text{Ингредиенты недельного меню}) - (\text{Фактическое наличие в холодильнике})$$
- **Группировка по отделам супермаркета:** Бакалея, Свежие овощи/фрукты, Мясной гастроном, Молочный отдел, Специи и соусы.
- **Интерактивный список:** интерфейс в стиле Google Keep с мгновенным вычеркиванием купленных позиций и синхронизацией состояния.

### 4.5. Модуль геолокации и ИИ-маршрутизации по магазинам ([class-store-locator.php](file:///c:/Users/Denis/Documents/antigravity/delightful-faraday/wordpress/wp-content/plugins/smart-fridge-chef/includes/class-store-locator.php))
- **Определение координат:** автоматическое геопозиционирование по GPS браузера или поиск по адресу города/улицы через OSM Nominatim.
- **Поиск кандидатов:** опрос геосервиса Overpass API в радиусе до 3000 метров с нахождением сетевых супермаркетов (*ВкусВилл, Перекрёсток, Пятёрочка, Магнит, Лента, Ашан*).
- **Математика расстояний:** расчет точного ортодромического расстояния по формуле гаверсинусов (Haversine formula):
  $$d = 2R \cdot \arcsin\left(\sqrt{\sin^2\left(\frac{\Delta \varphi}{2}\right) + \cos(\varphi_1)\cos(\varphi_2)\sin^2\left(\frac{\Delta \lambda}{2}\right)}\right)$$
  с пересчетом в пешее время в пути при средней скорости 4.8 км/ч.
- **Интеллектуальный рекомендатель магазина:** список недостающих продуктов вместе с найденными супермаркетами передается в языковую модель (Ollama Cloud / Claude):
  - При преобладании свежей зелени, фермерской молочки и органических продуктов $\rightarrow$ приоритет отдается сети *ВкусВилл*;
  - При наличии охлажденного мяса, рыбы, морепродуктов и сыров $\rightarrow$ приоритет *Перекрёстку*;
  - При стандартной базовой корзине (макароны, сахар, мука, яйца) $\rightarrow$ рекомендация *Пятёрочки* или *Магнита* с акцентом на экономию бюджета;
  - Формирование 3 практических советов по рациональной закупке.
- **Навигация:** прямые кнопки генерации пешего маршрута в **Яндекс Карты** (`yandex.ru/maps/?rtext=...`) и **Google Maps** (`google.com/maps/dir/?api=1...`).

### 4.6. Модуль администрирования и интеграций ([class-admin-settings.php](file:///c:/Users/Denis/Documents/antigravity/delightful-faraday/wordpress/wp-content/plugins/smart-fridge-chef/includes/class-admin-settings.php))
- Расположен в панели управления WordPress по адресу: `/wp-admin/admin.php?page=smart-fridge-chef`.
- Управление провайдерами: переключение между Ollama Cloud, Anthropic Claude, Google Gemini и Local Ollama.
- Валидация связи в один клик: кнопка «Проверить подключение к ИИ» выполняет реальный сетевой пинг и сообщает статус авторизации и задержку.

## 5. Спецификация программных интерфейсов (REST API)

Все запросы обслуживаются контроллером [`SFC_API_Controller`](file:///c:/Users/Denis/Documents/antigravity/delightful-faraday/wordpress/wp-content/plugins/smart-fridge-chef/includes/class-api-controller.php) по базовому пространству имен `/wp-json/fridge-chef/v1/`:

| Метод | Эндпоинт | Назначение | Входные параметры | Формат ответа |
|---|---|---|---|---|
| `POST` | `/analyze-input` | Распознавание продуктов по фото / тексту | `image` (Base64) или `text` (String) | `{"success": true, "products": [...]}` |
| `POST` | `/generate-recipes` | Подбор рецептов под список продуктов | `products`: `["яйца", "сыр", "помидоры"]` | `{"success": true, "recipes": [...]}` |
| `POST` | `/generate-weekly-plan` | Построение рациона на 7 дней и списка покупок | `products`: `[...]` | `{"success": true, "plan": {...}, "shopping_list": [...]}` |
| `POST` | `/find-stores` | Поиск магазинов и ИИ-рекомендация | `lat`, `lon`, `shopping_list`: `[...]` | `{"success": true, "recommendation": {...}, "stores": [...]}` |
| `POST` | `/save-meal-plan` | Сохранение рациона в базу данных WP | `title`, `plan_data` | `{"success": true, "post_id": 42}` |
| `GET` | `/saved-plans` | Получение списка ранее сохраненных меню | Отсутствуют | `{"success": true, "plans": [...]}` |
| `GET` | `/ai-status` | Проверка активного провайдера ИИ | Отсутствуют | `{"success": true, "provider": "ollama_cloud", ...}` |
| `POST` | `/test-ai` | Тестирование сетевой доступности ИИ | Отсутствуют | `{"success": true, "message": "OK", "model": ...}` |

## 8. Руководство по развертыванию и эксплуатации

### 8.1. Системные требования
- **ОС:** Microsoft Windows 10 / 11 (x64) или Windows Server 2019+.
- **Свободное место на диске:** от 300 МБ.
- **Внешние зависимости:** отсутствуют (все необходимые бинарные файлы интерпретатора PHP и база данных SQLite входят в состав репозитория).

### 8.2. Быстрый запуск в 1 клик
1. В корневом каталоге проекта дважды кликните на файл **[`start-server.bat`](file:///c:/Users/Denis/Documents/antigravity/delightful-faraday/start-server.bat)** (или выполните `./start-server.ps1` в терминале PowerShell).
2. Скрипт проверит окружение, запустит встроенный веб-сервер на порту `8000` и автоматически откроет в браузере страницу приложения:
   - **Главный интерфейс:** **[http://localhost:8000](http://localhost:8000)**
   - **Панель управления WordPress:** **[http://localhost:8000/wp-admin](http://localhost:8000/wp-admin)**
     - *Логин по умолчанию:* `admin`
     - *Пароль по умолчанию:* `admin12345`
3. Для завершения работы веб-сервера запустите **[`stop-server.bat`](file:///c:/Users/Denis/Documents/antigravity/delightful-faraday/stop-server.bat)**.

### 8.3. Настройка искусственного интеллекта (Ollama Cloud / Claude / Gemini)
Перейдите в панели администратора в раздел **«Умный Шеф»** ([http://localhost:8000/wp-admin/admin.php?page=smart-fridge-chef](http://localhost:8000/wp-admin/admin.php?page=smart-fridge-chef)):

1. **Режим «Ollama Cloud»:**
   - Выберите провайдер **Ollama Cloud**.
   - Укажите базовый URL (по умолчанию `https://ollama.com` или адрес вашего облачного прокси-шлюза).
   - Введите ваш **Ollama Cloud API Key** / Bearer Token.
   - Модель: `llama3.2-vision`, `qwen2-vl` или `claude-3-5-sonnet`.
   - Нажмите **«Сохранить настройки»** и затем **«Проверить подключение к ИИ»**.
2. **Режим «Anthropic Claude»:**
   - Выберите провайдер **Anthropic Claude**.
   - Вставьте API-ключ формата `sk-ant-api03-...`.
   - Модель: `claude-3-5-sonnet-20241022` (рекомендуется для анализа фото) или `claude-3-haiku-20240307`.
3. **Режим «Локальная Ollama»:**
   - Выберите **Ollama (Локальный сервер)**.
   - URL: `http://localhost:11434`.
   - Предварительно запустите модель в вашей консоли: `ollama run llama3.2-vision`.

## 10. Заключение и перспективы развития

Разработанный программный комплекс «Smart Fridge Chef» представляет собой завершенное инженерное решение на стыке классической CMS (WordPress), мультимодальных нейросетевых технологий и геоинформационных сервисов. 

### Планируемые направления расширения функционала:
1. **PWA (Progressive Web App):** добавление Service Worker и Web App Manifest для установки приложения на экраны смартфонов iOS и Android в качестве нативного веб-приложения с поддержкой офлайн-режима.
2. **Сканирование штрих-кодов (EAN-13 / DataMatrix):** интеграция с открытыми базами данных продовольственных товаров для моментального добавления упакованных продуктов в инвентарь.
3. **Прямая интеграция со службами доставки:** передача сформированного списка покупок через открытые партнерские API в сервисы экспресс-доставки (Самокат, Яндекс Лавка, Купер).
4. **Персонализированные профили диет:** расширение профилей питания под лечебные столы, аллергии (лактоза, глютен, орехи) и спортивные макросы.
