## «Умный Шеф: Холодильник & Рацион» (Smart Fridge Chef)
### Программный комплекс на базе WordPress с мультимодальным ИИ и геомодулем

## 1. Паспорт проекта и общие сведения

- **Наименование проекта:** Программный комплекс «Smart Fridge Chef» («Умный Шеф: Холодильник & Рацион»).
- **Платформа реализации:** [WordPress 6.x](./wordpress) (Headless CMS / REST API + Single Page Application Frontend).
- **Среда исполнения:** Автономная портативная среда [PHP 8.3 x64](./tools/php/php.exe) со встроенной реляционной СУБД SQLite 3 (не требует развертывания Docker или служб MySQL).
- **Дизайн-система:** Строгая редакционная типографика (Lora, Montserrat, Roboto), векторная иконография Google Material Symbols, полное отсутствие визуального шума и псевдо-стикеров.
- **Интеллектуальное ядро:** Мультипровайдерный AI-модуль с поддержкой **Anthropic Claude (Claude 3.5 Sonnet / Haiku)**, **Ollama Cloud**, локальной **Ollama** (`llama3.2-vision`, `llava`, `qwen2-vl`), **Google Gemini** и детерминированного экспертного кулинарного движка (Rule-based Fallback Engine).
- **Версия продукта:** `1.3.0 (Production-Ready)`.

## 2. Актуальность и проблематика

Современный человек ежедневно сталкивается с тремя взаимосвязанными бытовыми проблемами:
1. **Нерациональное использование продуктов питания (Food Waste):** по статистике до 25–30% купленных продуктов выбрасываются из-за истечения срока годности или забывания того, что находится на полках холодильника.
2. **Когнитивная нагрузка при планировании питания:** ежедневный выбор блюд на завтрак, обед и ужин отнимает время, приводит к однообразному рациону и нарушению баланса белков, жиров, углеводов и калорийности (КБЖУ).
3. **Неэффективная логистика покупок:** составление списков покупок вручную часто приводит к дублированию позиций, покупке лишнего и выбору неподходящего магазина.

**Цель проекта:** разработать легкий, автономный и интуитивно понятный программный комплекс, позволяющий пользователю по одной фотографии холодильника или списку ингредиентов сформировать персональную базу продуктов, мгновенно сгенерировать адаптивные рецепты, составить сбалансированное меню на неделю с вариативностью замены блюд, рассчитать точный список недостающих ингредиентов и найти **100% реальные супермаркеты** поблизости с помощью открытых картографических сервисов и нейросетей.

### Стек технологий:
- **Бэкенд:** PHP 8.3 x64, WordPress 6.7.x, WordPress REST API, cURL, GD Image Processing (WebP сжатие и генерация миниатюр), JSON Schema.
- **База данных:** Реляционная СУБД SQLite 3 через официальный drop-in драйвер `db.php` команды WordPress Core (гарантирует zero-dependency переносимость без сторонних СУБД-серверов).
- **Интерфейс:** Семантический HTML5, чистый CSS3 со строгой редакционной типографикой, чистый ES6+ JavaScript без тяжелых внешних фреймворков (Vue/React), обеспечивающий мгновенный отклик (<50 мс).
- **Картография и геомодуль:** Geolocation API браузера, OpenStreetMap Nominatim Live Bounded Search (без галлюцинаций и фейковых сетей), картографический движок Leaflet 1.9.4, прямое построение пеших маршрутов в Яндекс Карты и Google Maps по точным координатам.

## 4. Функциональная структура программного комплекса

### 4.1. Модуль компьютерного зрения и инвентаризации продуктов ([class-ai-engine.php](./wordpress/wp-content/plugins/smart-fridge-chef/includes/class-ai-engine.php))
- **Загрузка и предобработка изображений:** поддержка Drag & Drop, выбора файлов с диска и прямой съемки с камеры мобильного устройства.
- **WebP оптимизация и миниатюры:** перед отправкой изображение оптимизируется на Canvas в формат WebP, а серверный обработчик [class-image-handler.php](./wordpress/wp-content/plugins/smart-fridge-chef/includes/class-image-handler.php) сохраняет основной файл и генерирует легкую миниатюру 400x300 для моментальной загрузки.
- **Мгновенный автоподбор рецептов:** сразу после завершения загрузки фото система автоматически распознает ингредиенты и тут же производит расчет подходящих блюд и недельного меню без лишних кликов.

### 4.2. Модуль подбора рецептов и расчета пищевой ценности
- **База рецептур:** содержит каталогизированные рецепты русской, европейской, средиземноморской и азиатской кухонь.
- **Вариативность и разделение:**
  - *«Можно приготовить сразу»* — рецепты, полностью обеспеченные имеющимися продуктами из холодильника.
  - *«С докупкой ингредиентов»* — рецепты, требующие докупить 1–3 недостающих продукта, с мгновенным отображением того, что именно нужно приобрести.
- **Расчет КБЖУ:** для каждого рецепта вычисляется и отображается калорийность, белки, жиры, углеводы и время приготовления.
- **Инструкции по приготовлению:** пошаговые сценарии термообработки и подготовки ингредиентов.

### 4.3. Модуль генератора недельного рациона (Meal Planner)
- **Структура на 7 дней:** автоматическое распределение приемов пищи (Завтрак, Обед, Ужин, Перекус) с понедельника по воскресенье.
- **Интерактивная замена блюд (Meal Swap):** пользователь может в один клик заменить любое блюдо дня на альтернативное с пересчетом списка покупок.
- **Оптимизация остатков:** алгоритм планирует меню таким образом, чтобы скоропортящиеся продукты из холодильника использовались в первые 2–3 дня недели.
- **Персистентность:** сохранение готового недельного плана в базу данных WordPress как кастомный тип записи [`sfc_meal_plan`](./wordpress/wp-content/plugins/smart-fridge-chef/includes/class-post-types.php) с возможностью повторного открытия.

### 4.4. Модуль разностного расчета корзины покупок (Shopping List Diff)
- **Формула расчета:**
  $$\text{Список к закупке} = \sum (\text{Ингредиенты недельного меню}) - (\text{Фактическое наличие в холодильнике})$$
- **Группировка по отделам супермаркета:** Бакалея, Свежие овощи/фрукты, Мясной гастроном, Молочный отдел, Специи и соусы.
- **Интерактивный список:** интерфейс с мгновенным вычеркиванием купленных позиций и синхронизацией состояния.

### 4.5. Модуль реального геопоиска и навигации ([class-store-locator.php](./wordpress/wp-content/plugins/smart-fridge-chef/includes/class-store-locator.php))
- **100% реальные данные без выдумок:** система обращается к OpenStreetMap Nominatim Live Search в ограниченном географическом окне координат вокруг пользователя. Все синтетические генераторы сетей полностью исключены.
- **Определение локации:** запрос реальной геолокации браузера пользователя или поиск по любому введенному вручную адресу/городу (Москва по умолчанию полностью устранена).
- **Математика расстояний:** расчет точного ортодромического расстояния по формуле гаверсинусов (Haversine formula):
  $$d = 2R \cdot \arcsin\left(\sqrt{\sin^2\left(\frac{\Delta \varphi}{2}\right) + \cos(\varphi_1)\cos(\varphi_2)\sin^2\left(\frac{\Delta \lambda}{2}\right)}\right)$$
  с пересчетом в пешее время в пути при средней скорости 4.8 км/ч.
- **Универсальное распознавание магазинов:** корректно определяет сетевые и локальные супермаркеты в любых странах и регионах (Беларусь: *Евроопт*, *Санта*, *Корона*, *Гиппо*, *Соседи*; Казахстан: *Magnum*, *Small*, *Galmart*; Грузия: *Fresco*, *Nikora*; Европа: *Biedronka*, *Carrefour*, *Lidl*, *Spar*; любые местные продуктовые универсамы).
- **Навигация:** прямые кнопки генерации пешего маршрута в **Яндекс Карты** (`yandex.ru/maps/?rtext=...`) и **Google Maps** (`google.com/maps/dir/?api=1...`) по точным географическим координатам магазина.

### 4.6. Модуль администрирования и интеграций ([class-admin-settings.php](./wordpress/wp-content/plugins/smart-fridge-chef/includes/class-admin-settings.php))
- Расположен в панели управления WordPress по адресу: `/wp-admin/admin.php?page=smart-fridge-chef`.
- Управление провайдерами: переключение между Ollama Cloud, Anthropic Claude, Google Gemini и Local Ollama.
- Валидация связи в один клик: кнопка «Проверить подключение к ИИ» выполняет реальный сетевой пинг и сообщает статус авторизации и задержку.

## 5. Спецификация программных интерфейсов (REST API)

Все запросы обслуживаются контроллером [`SFC_API_Controller`](./wordpress/wp-content/plugins/smart-fridge-chef/includes/class-api-controller.php) по базовому пространству имен `/wp-json/fridge-chef/v1/`:

| Метод | Эндпоинт | Назначение | Входные параметры | Формат ответа |
|---|---|---|---|---|
| `POST` | `/analyze-input` | Распознавание продуктов по фото / тексту | `image_base64` или `text` | `{"success": true, "products": [...]}` |
| `POST` | `/generate-recipes` | Подбор рецептов под список продуктов | `products`: `[...]` | `{"success": true, "ready_now": [...], "need_more": [...]}` |
| `POST` | `/generate-weekly-plan` | Построение рациона на 7 дней и списка покупок | `products`: `[...]` | `{"success": true, "plan": [...], "shopping_list": [...]}` |
| `POST` | `/find-stores` | Реальный поиск супермаркетов на карте | `lat`, `lon` или `query`, `shopping_list` | `{"success": true, "stores": [...], "recommendation": {...}}` |
| `POST` | `/save-meal-plan` | Сохранение рациона в базу данных WP | `title`, `plan_data` | `{"success": true, "post_id": 42}` |
| `GET` | `/saved-plans` | Получение списка ранее сохраненных меню | Отсутствуют | `{"success": true, "plans": [...]}` |
| `GET` | `/ai-status` | Проверка активного провайдера ИИ | Отсутствуют | `{"success": true, "provider": "ollama_cloud", ...}` |
| `POST` | `/test-ai` | Тестирование сетевой доступности ИИ | Отсутствуют | `{"success": true, "message": "OK", "model": ...}` |

## 6. Пользовательский интерфейс и дизайн-система

Интерфейс спроектирован с полным отказом от «ИИ-слопа» (хаотичных градиентов, избыточных неоновых подсветок, эмодзи-перегрузки и плавающих стикеров):

1. **Типографика:**
   - **Lora:** элегантный заголовочный шрифт для названий рецептов и ключевых разделов.
   - **Montserrat:** акцентный шрифт для кнопок действий, табов и метаданных.
   - **Roboto:** сбалансированный гротеск для основного текста, описаний ингредиентов и шагов приготовления.
2. **Иконография:** векторные монохромные пиктограммы **Google Material Symbols Outlined** (набор Google Fonts).
3. **Карточки блюд и планировщик:** соотношение сторон карточек рецептов, чистые бейджи времени приготовления и калорийности, переключение приемов пищи по дням недели, модальные окна с пошаговой инструкцией.
4. **Интерактивные списки:** списки покупок с возможностью мгновенного вычеркивания без перезагрузки экрана.

## 8. Руководство по развертыванию и эксплуатации

### 8.1. Системные требования
- **ОС:** Microsoft Windows 10 / 11 (x64) или Windows Server 2019+.
- **Свободное место на диске:** от 300 МБ.
- **Внешние зависимости:** отсутствуют (все необходимые бинарные файлы интерпретатора PHP и база данных SQLite входят в состав репозитория).

### 8.2. Быстрый запуск в 1 клик
1. В корневом каталоге проекта дважды кликните на файл **[`start-server.bat`](./start-server.bat)** (или выполните `./start-server.ps1` в терминале PowerShell).
2. Скрипт проверит окружение, запустит встроенный веб-сервер на порту `8000` и автоматически откроет в браузере страницу приложения:
   - **Главный интерфейс:** **[http://localhost:8000](http://localhost:8000)**
   - **Панель управления WordPress:** **[http://localhost:8000/wp-admin](http://localhost:8000/wp-admin)**
     - *Логин по умолчанию:* `admin`
     - *Пароль по умолчанию:* `admin12345`
3. Для завершения работы веб-сервера запустите **[`stop-server.bat`](./stop-server.bat)**.

### 8.3. Настройка искусственного интеллекта (Ollama Cloud / Claude / Gemini)
Перейдите в панели администратора в раздел **«Умный Шеф»** ([http://localhost:8000/wp-admin/admin.php?page=smart-fridge-chef](http://localhost:8000/wp-admin/admin.php?page=smart-fridge-chef)):

1. **Режим «Ollama Cloud»:**
   - Выберите провайдер **Ollama Cloud**.
   - URL: `https://api.ollama.com`.
   - Введите ваш **Ollama Cloud API Key** / Bearer Token.
   - Модель: `llama3.2-vision`, `qwen2-vl` или `claude-3-5-sonnet`.
   - Нажмите **«Сохранить настройки»** и затем **«Проверить подключение к ИИ»**.
2. **Режим «Anthropic Claude»:**
   - Выберите провайдер **Anthropic Claude**.
   - Вставьте API-ключ формата `sk-ant-api03-...`.
   - Модель: `claude-3-5-sonnet-20241022` или `claude-3-haiku-20240307`.
3. **Режим «Локальная Ollama»:**
   - Выберите **Ollama (Локальный сервер)**.
   - URL: `http://localhost:11434`.
   - Предварительно запустите модель в консоли: `ollama run llama3.2-vision`.
4. **Резервный автономный режим:**
   - Если API-ключи не заданы или отсутствует интернет-соединение, система автоматически переключается на встроенный экспертный движок, сохраняя 100% работоспособность всех вкладок приложения.
