# Инструкция по запуску проекта «Умный Шеф»

Проект полностью автономен: все бинарные файлы интерпретатора PHP 8.3 x64 и встроенная реляционная база данных SQLite уже включены в состав репозитория. Дополнительно устанавливать Docker, Apache, Nginx или MySQL **не требуется**.

---

## 1. Клонирование репозитория

```bash
git clone https://github.com/ZubokDenis/smart-fridge-chef.git
cd smart-fridge-chef
```

---

## 2. Быстрый запуск

### Вариант 1: Запуск в 1 клик (Windows Explorer)
Просто дважды кликните мышью по файлу **`start-server.bat`** в корне папки проекта. 
Скрипт автоматически проверит файлы, запустит встроенный веб-сервер на порту `8000` и откроет страницу приложения в браузере.

### Вариант 2: Запуск через PowerShell
Откройте PowerShell в папке проекта и выполните:
```powershell
./start-server.ps1
```

### Вариант 3: Ручной запуск через командную строку
```powershell
.\tools\php\php.exe -S 127.0.0.1:8000 -t wordpress wordpress/router.php
```

---

## 3. Адреса и учетные данные

После запуска сервер доступен по следующим ссылкам:

| Раздел | URL | Учетные данные |
|---|---|---|
| **Главный экран приложения** | [http://localhost:8000](http://localhost:8000) | Доступ свободный (без авторизации) |
| **Панель управления WordPress** | [http://localhost:8000/wp-admin](http://localhost:8000/wp-admin) | **Логин:** `admin`<br>**Пароль:** `admin12345` |
| **Страница настроек ИИ** | [http://localhost:8000/wp-admin/admin.php?page=smart-fridge-chef](http://localhost:8000/wp-admin/admin.php?page=smart-fridge-chef) | Доступна после входа в админку |

---

## 4. Остановка веб-сервера

- Дважды кликните по файлу **`stop-server.bat`** в корне проекта.
- Либо нажмите комбинацию клавиш `Ctrl + C` в окне терминала, в котором работает сервер.

---

## 5. Настройка провайдеров ИИ

В админ-панели в разделе **«Умный Шеф»** вы можете переключить провайдер обработки изображений и генерации меню:

1. **Ollama Cloud:**
   - Выберите `Ollama Cloud`.
   - URL по умолчанию: `https://api.ollama.com` (или ваш собственный хост).
   - Введите ваш **API Key / Bearer токен** (если требуется).
   - Модель: `deepseek-v4.1-flash`, `llama3.2-vision`, `mistral-large-4` или `qwen2-vl`.
   - Нажмите кнопку **«Проверить подключение к ИИ»**.
2. **Anthropic Claude:**
   - Выберите `Anthropic Claude`.
   - Вставьте API-ключ формата `sk-ant-api03-...`.
   - Модель: `claude-3-5-sonnet-20241022` или `claude-3-haiku-20240307`.
3. **Автономный экспертный режим:**
   - Если API-ключи не заданы или отсутствует интернет-соединение, система автоматически работает на встроенном детерминированном кулинарном движке — все вкладки, рецепты, меню на неделю и геопоиск магазинов остаются на 100% функциональными.

## 6. Основные возможности в интерфейсе

- **Вкладка 1 (Холодильник):** перетащите фото продуктов на область загрузки или введите их текстом. Изображение мгновенно пережимается в WebP с созданием миниатюр. Сразу после загрузки фото приложение в фоновом режиме запускает расчет рецептов.
- **Вкладка 2 (Рецепты):** карточки разбиты на вариации: *«Можно приготовить сразу»* (из имеющихся продуктов) и *«С докупкой ингредиентов»* (показывает, что именно нужно докупить).
- **Вкладка 3 (План на неделю):** меню на 7 дней с КБЖУ и возможностью замены любого блюда в 1 клик.
- **Вкладка 4 (Список покупок):** разностный список недостающих продуктов для меню недели.
- **Вкладка 5 (Магазины):** нажмите кнопку «Мое местоположение» или введите любой город/улицу в поле поиска. Карта выполняет **реальный поиск по OpenStreetMap**, находит супермаркеты вокруг вас и строит прямые пешие маршруты в Яндекс Картах и Google Maps.
